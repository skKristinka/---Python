# Правила работы с репозиторием

## Ветки
- `main` — стабильная версия, прямые коммиты запрещены
- `develop` — интеграционная ветка
- `feature/<название>` — работа над задачей (например, `feature/url-parser`)

## Процесс
1. `git checkout develop && git pull`
2. `git checkout -b feature/<название>`
3. Коммиты небольшие, сообщения вида `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`
4. `git push -u origin feature/<название>` и Pull Request в `develop`
5. Merge только после прохождения CI и ревью

## Требования к коду
- docstring у каждого класса и метода
- `flake8 src/ tests/` без ошибок
- сокеты и файлы — только через `with`
- без глобального состояния
