# Отчёт: HTTP-клиент и сервер с GUI на Python

**Автор:** _ФИО_  **Группа:** _…_  **Репозиторий:** https://github.com/skKristinka/---Python

## 1. Цель и постановка задачи

Разработать десктопное приложение на Python с GUI: HTTP-клиент (GET/POST) и HTTP-сервер (маршруты `/`, `/echo`, `/time`, `/headers`, `/status/<code>`), реализованные на сокетах; освоить ООП-архитектуру и многопоточность в GUI.

## 2. Архитектура

Слои: `http` → `net` → `client` / `server` → `gui`. Два интерфейса (ABC): `Transport` (`Socket`) и `RequestHandler` (`Router`).

## 3. Реализация по этапам

| Этап | Что сделано |
|---|---|
| 1. Парсинг и сериализация | `Url`, `Parser`, `Serializer`, исключения; unit-тесты, в т. ч. граничные случаи |
| 2. Сокеты и клиент | `Socket` (контекстный менеджер), `TcpClient`, `HttpClient`, `read_message`; таймаут, chunked, редиректы, https |
| 3. Сервер | `TcpServer`, `HttpServer` (поток на соединение, keep-alive), `Router`, обработчики; остановка по флагу |
| 4. GUI | Tkinter: вкладки «Клиент», «Сервер», «Настройки»; фоновые потоки, `queue.Queue` + `root.after` |
| 5. Интеграция и качество | интеграционные тесты, `python -X dev`, flake8/pylint, README, документация |

## 4. Многопоточность

_Кратко (подробнее — в documentation.md, раздел 4):_ запрос клиента и сервер работают в фоновых потоках; результаты и лог передаются в главный поток через `queue.Queue` и забираются по `root.after`; остановка сервера — флаг `threading.Event` + закрытие сокетов.
